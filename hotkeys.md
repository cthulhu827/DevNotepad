# Горячие клавиши DevNotepad

## Основное окно (вкладки)

| Клавиша | Действие |
|---|---|
| `Ctrl+T` | Создать новую вкладку |
| `Ctrl+Tab` | Переключиться на следующую вкладку |
| `Ctrl+Shift+Tab` | Переключиться на предыдущую вкладку |

## Рабочая область (панель трансформации)

| Клавиша | Действие |
|---|---|
| `F1` | Вставить текст из буфера обмена в поле «Источник» |
| `F2` | Скопировать результат трансформации в буфер обмена |
| `F4` | Редактировать активный элемент пайплайна |
| `Insert` | Добавить новый трансформер в конец пайплайна |

## Пайплайн (конвейер трансформеров)

| Клавиша | Действие |
|---|---|
| `←` / `→` | Перемещение по элементам пайплайна |
| `Home` | Перейти к первому элементу |
| `End` | Перейти к последнему элементу |
| `Ctrl+←` | Вставить новый трансформер **перед** текущим |
| `Ctrl+→` | Вставить новый трансформер **после** текущего |
| `Enter` | Выйти из фокуса пайплайна (вернуть фокус предыдущему контролу) |
| `Alt+Enter` | Редактировать текущий трансформер |
| `Alt+Shift+Enter` | Редактировать текущий трансформер (расширенный режим) |
| `Delete` | Удалить выбранный трансформер |

## Диалог выбора трансформера

| Клавиша | Действие |
|---|---|
| `↓` / `↑` | Навигация по списку трансформеров |

## Текстовые поля

| Клавиша | Действие |
|---|---|
| `Shift + колесо мыши` | Горизонтальная прокрутка текста |
| `Колесо мыши` | Вертикальная прокрутка текста |

## Изменение размера панелей

| Клавиша | Действие |
|---|---|
| `Escape` | Отмена изменения размера панелей (во время перетаскивания разделителя) |

## Трансформеры

| Клавиша | Действие |
|---|---|
| `Alt+G` | Grep |
| `Alt+T` | Template |
| `Alt+D` | Double quotes |
| `Alt+S` | Single quotes |
| `Alt+A` | Take after |
| `Alt+B` | Take before |
